# Rei's Voyage to Three — Final Edition

Upload the contents of this folder to the root of the GitHub Pages repository.

## Included features
- Interactive day/night sun and moon toggle
- Animated stars, butterflies by day, and fireflies by night
- Sandy shoreline with sparkling shells, starfish, and a wandering crab
- Gently bobbing canoe and layered animated waves
- Illustrated opening treasure chest (no toolbox emoji)
- Rei's clothing size: 3T
- Rei's shoe size: 7
- Updated shared Amazon Wishlist link
- Countdown, RSVP, text, and Google Maps links
- Mobile-friendly and reduced-motion support

Keep Rei's photo at `assets/rei-photo.jpg`.
